# 1.0.9

## 功能添加

- **中部显示三个组件**：基础外观 → 中部显示三个组件，开启后胶囊中部可同时放三个组件；左右内边距与两段间距取同一个「胶囊内边距」值，胶囊按实际内容加宽。默认关闭。
- **5GA 显示方式**：网络类型 → 5GA 显示方式，可选「5GA」或「5A」，只影响 5GA 这一种制式的写法，其他制式不变。

## 功能修复

- **网络类型停留在 5G**：关闭 5G 后仍显示 5G，原因是 ROM 的每卡制式表保留了 NSA 的 NR 覆盖；现在以无线电实际上报为准，该表只在读不到时兜底。
- **胶囊制式消失**：胶囊里的网络类型文本原来只认原生制式图标，关掉 5G 后系统不再画该图标，文本就空了；现在优先取数据卡的电话读数，图标名只做补充。
- **生效钩子数显示 0**：关于 → 生效钩子数原来由系统界面进程写入，被设置进程整份重写配置时覆盖，永远读回 0；现在按当前开启的功能在设置进程内直接统计。
- **上下开口的组件偏右**：开口切口原来按每字符 0.31em 估算，比实际绘制宽度窄，文字压到两侧弧线上；现在按实际字符串测量切口，并按字形排布居中。
- **圆环中部偏低**：圆环样式下，放在中部的读数、时间与图标整体比圆心低约 2.5 个单位；中部改为以圆心为基准，与左右两格同一口径。
- **圆环随放置缩小**：上下放了组件后整环变小，即使那一帧什么都没画；原因是按放置内容加高了墨迹盒，而状态栏高度固定。现在圆环尺寸与放置内容无关。
- **圆环上下组件字体偏小**：开口宽度按实际文字测量后，长读数（时间等）不再被压成小字，切口会为它让开。
- **环内信号点与开口错位**：平放的两排点落在开口内并保留行距，弧状两排跨在环带上；外排弧更长、点距更大，不会压到弧线端头或溢出状态栏。
- **环内信号点设置无效**：信号条粗细、信号点间距两个滑杆现在同时作用于环内点排的直径与行距/点距。
- **胶囊右侧被裁切**：组件数量或读数变化后胶囊会加宽，但视图宽度仍停在首次测量的值，多出的部分落到右侧；现在按所需宽度直接比较并重新测量。

## 功能变更

- **信号点开关**：卡一、卡二信号点放入布局后，移动信号面板里对应的「显示卡一/卡二信号点」开关不再显示，避免与放置状态互相矛盾。

---

**安装**：覆盖安装即可，设置全部保留。涉及 SystemUI hook 的更新需要重新加载系统界面后生效。
