# 1.0.3

## 功能添加
- **时间数字独立颜色**：功能设置 → 状态栏时钟，可点击时间预览中的每一个数字单独指定专属颜色，深浅色分别保存，支持一键清空或单字重置。
- **电池电流读数**：组件外观 → 读数值，新增电流读数开关，支持放置在圆环、胶囊与环外读数条任意区域；支持切换毫安（mA）与安培（A）单位，支持始终显示正值开关。
- **温度与功率刷新频率**：组件外观 → 读数值，新增刷新频率滑块（默认 10s，可调 5–120s），增大间隔更省电。
- **备份恢复**：首页新增备份与恢复卡片，支持将完整模块配置导出为 JSON 备份文件，或从外部文件恢复并即时生效。
- **日志页面**：首页新增模块日志独立页面，支持动态调节日志级别（默认关闭），实时捕获与查看 Hook 日志；可按级别与关键字筛选，日志以 `.txt` 文件分享到任意可接收文件的应用。
- **关于页面**：参考现代化卡片架构提取独立关于页，集中收拢仓库主页、检查更新与更新说明；发现新版本弹窗支持「不再提示此版本」固定开关。

## 功能修复
- **时间放进三合一后，左侧系统时钟不再擅自返回**：圆环、胶囊都受同一套判定与每次状态栏重排的校正；系统时钟只在三合一确实画出时间时才隐藏，不会再出现「时钟被隐藏了但胶囊里也没显示」的空白。
- **胶囊开口组件字号设置失效**：胶囊顶部与底部开口重新平衡可用几何空间与基线，解决添加的所有组件默认字号偏小且滑块无法放大的缺陷。
- **温度告警色不再闪烁**：组件外观 → 硬件读数，电池温度停在高温阈值附近时（例如 39°C 与 40°C 之间来回一跳），告警色不再反复切换；进入高温色后需回落 1°C 才恢复常规色。
- **过热时提前变色**：系统因过热限制性能时，温度读数立即以告警色显示，不再等电池温度自己越过阈值才提醒。
- **胶囊加长后闪电贴住右缘**：胶囊样式里，充电闪电与 Wi-Fi 弧现在和左侧数字共用同一份间距设置，右侧留白与左侧一致，不再出现闪电压在胶囊边缘甚至溢出。

## 功能变更
- **底栏结构重排与首页引导**：原「关于」Tab 改名为「首页」并移至第一个 Tab 显示，包含未激活/作用域缺失横幅预警、设备型号与系统指纹展示；初次安装进入默认展示首页，后续进入直达排布页面。
- **状态栏不显示时暂停刷新**：全屏应用隐藏状态栏、锁屏等状态下，温度、充电功率、电流、帧率、天气与时钟的刷新一并暂停；状态栏重新出现时自动补一次更新，读数不会停在旧值。
