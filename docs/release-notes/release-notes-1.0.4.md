# 1.0.4

## 新增功能
- **新增电池电压读数**：支持在状态栏实时显示电池当前电压（如 3.85V）；开启路径在「功能设置 → 性能读数 → 电池电压」，与功率、温度、电流、帧率无缝协同参与顺序自适应堆叠。
- **读数刷新频率全覆盖**：读数刷新频率（默认 10s，可调 1–120s）现在同时统一接管充电功率、电池温度、电池电流与电池电压的回读周期，进一步优化日常待机续航。

## 问题修复
- **读数自适应堆叠与独立显示**：修复开启多项读数时挤压为三行导致文字过小的缺陷；现在单组严格限制最多双行堆叠，多于两项时自适应拆分并建立第二组读数，根据开启顺序智能两两成对或独立大字号显示。
- **状态栏原生时钟重叠**：修复在特定场景下原生系统时间与模块时间同时出现在左上角或时间重叠的缺陷，强化状态栏时钟冲突抑制；优化「隐藏状态栏时钟」开关文案。
- **电池电流与功率显示优化**：修复在部分机型上电池电流显示为 0mA 或单位异常的问题，优化电流与功率的动态刷新联动，默认以安培（A）单位更直观呈现。
- **模块总开关完备覆盖**：修复关闭模块总开关后通知中心隐藏按钮、天气与图标替换未即时归零还原的问题；关闭总开关时所有增强功能即刻无缝交还系统。
- **通知中心与天气即时还原**：关闭通知中心隐藏按钮或关闭天气时，界面即刻响应恢复原生样式，无需等待下一分钟或重启系统界面。
- **状态栏时钟即时卸载**：优化自定义时钟卸载链路，关闭时钟天气或关闭模块时主线程即刻移除自定义视图并恢复原生时钟，解决关闭天气后时钟残留与延迟问题。
- **首页已开启项统计修复**：修复未开启「三合一图标合并」时首页已开启组件统计显示为 0 的问题，精准统计当前处于生效状态的全部功能数。
- **胶囊帧率放置修复**：修复将帧率添加至胶囊布局后无法正常绘制的问题。
- **Wi-Fi 弧开孔自适应缩放**：修复胶囊和圆环开口处 Wi-Fi 弧外圈与底部被边缘截断的问题，自适应保留安全边距。
- **滑块拖动调参防抖**：修复滑动调节尺寸等参数时状态栏读数跟随高频重新读取、剧烈跳动的缺陷，彻底消除滑动调参时的读数异常闪烁。

## 体验与性能优化
- **息屏与后台待机零开销**：在息屏待机、全屏游戏或视频时，后台时钟定时器、帧动画调度与未开启的天气查询自动进入完全休眠，消除不必要的后台耗电。
- **底层运行能效提升**：重构底层反射与系统资源访问机制，建立高速无锁并发缓存，消除高频界面重绘与测量过程中的运算损耗，大幅降低状态栏高刷运行负载。
