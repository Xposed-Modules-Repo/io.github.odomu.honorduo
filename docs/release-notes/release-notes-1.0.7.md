# 1.0.7
> **重要说明**：1.0.6 存在状态栏时间偶发消失、下拉闪烁、双行时钟截断、颜色不同步，以及隐藏隐私提示后电池区域仍短暂消失的问题。

## 功能修复
- **胶囊样式左右两侧留白**：组件外观 → 摆放，左右两侧的 Wi-Fi 位只在实际连上 Wi-Fi 时占位；关闭 Wi-Fi 或未连接时不再空出一道，字形重新居中。
- **胶囊下方副卡信号点**：胶囊下沿放置 SIM 1 / SIM 2 后，每张卡按自己的信号强度点亮，不再固定显示为未激活。
- **预览与真机一致**：设置页预览与状态栏用同一份 Wi-Fi 状态计算占位，预览里看到的宽度就是状态栏里的宽度。
- **状态栏时钟**：取消额外挂载、迁移时钟视图和重复恢复，保留系统时钟本身的布局与动画目标，减少下拉及切换界面时的消失、闪烁。
- **横屏下拉后时钟异常**：横屏时下拉通知栏，时间会缩成看不见的一点；区分未解析的高度与父布局明确约束，避免使用错误的缩放预算。
- **状态栏颜色同步**：字形和环外组件按自身显示位置跟随系统染色，不再借用隐藏电池的旧位置；时间保留系统原生染色及用户自定义颜色。
- **系统隐私提示兼容**：修复状态栏颜色刷新与系统动画之间的显示冲突。
- **恢复配置立即生效**：恢复备份后，农历开关、日期/星期格式、上下行偏移、行距、间距与颜色会一并同步到状态栏，不再需要再改一次设置才显示。
- **减少状态栏重复布局**：状态栏布局同步只在尺寸、顺序或内容实际变化时更新，避免下拉和高频刷新时重复测量。

---

**安装**：覆盖安装即可，设置全部保留。涉及 SystemUI hook 的代码更新需要在系统界面重新加载后生效。
