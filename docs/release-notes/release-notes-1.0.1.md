# 1.0.1

## 功能添加
- **温度状态颜色**：功能设置 → 硬件读数，新增状态颜色开关（默认关闭），开启后电池温度超过阈值以高亮告警色显示。
- **替换状态图标**：功能设置 → 基础外观，新增状态图标替换开关，支持将闹钟、NFC、热点、VPN、蓝牙、静音、勿扰等状态栏系统图标替换为内置风格。
- **替换 WiFi 图标**：功能设置 → 无线网络，新增 WiFi 图标替换开关，支持将状态栏 WiFi 图标替换为内置风格（完整支持 WiFi 5 / 6 / 7 等）。
- **圆环双卡双排堆叠**：组件排布 → 移动网络，当双卡放置在圆环内时支持双排同心堆叠显示信号点，外轮廓对称并严格对齐正圆几何外径。
- **圆环间距微调**：功能设置 → 基础外观，新增左右间距与上下间距微调滑块，支持自由调节圆环圆弧与内部读数的相对间距。
- **自定义字体导入**：关于模块 → 字体，支持从设备本地导入 `.ttf` / `.otf` 自定义字体应用于三合一所有文本与读数，并支持一键恢复系统字体。
- **充电闪电动画**：功能设置 → 电池电量，新增启用充电动画开关，支持呼吸、流光、电火花动画风格及速度调节。
- **组件快捷调位与自动激活**：组件排布弹窗顶部新增位置下拉，可快速调整环内放置区域；在排布区添加未开启的组件时，自动同步激活对应功能开关。
- **在线更新日志与新版提醒**：关于模块 → 更新，新增「更新日志」入口，支持在线获取并查阅版本说明；检测到新版本时在状态文本旁呈现红点提示徽标。

## 功能修复
- **温度样式与阈值即时生效**：修复修改电池高温告警阈值及重置颜色时无法立刻生效的问题，高温颜色重置时恢复为默认红色。
- **颜色配置默认浅色 Tab**：颜色配置弹窗默认选中浅色背景 Tab，避免在浅色界面调试时因修改深色配置误以为未生效。
- **恢复默认语义统一**：统一全界面恢复默认按钮与确认弹窗提示，消除原先“三种状态颜色”的旧文案限制。
- **应用更新下载与安装**：修复下载新版本时缺少进度反馈与重复弹窗提示的问题，新增实时百分比与线性进度指示，下载完成后自动唤起系统安装器。
- **信号配置环内适配**：修复「仅显示上网卡」和 4 柱 / 5 柱样式在圆环及胶囊内未生效的问题，使环内与环外保持统一显示行为。
- **状态栏自定义时钟排版**：修复状态栏时钟无法双行堆叠显示日期星期的问题，并屏蔽横屏下拉通知栏时系统误加的左侧偏移量，时钟自然居左。
- **状态栏胶囊避让与层级稳定性**：被展开胶囊覆盖的系统图标严格隐藏，解决图标显示半截问题；同时消除下拉通知栏时由于视图层级冲突导致的空指针闪退。
- **圆环读数字号与几何空间**：优化网络类型与电量读数在圆环内的默认字号与空间预算，消除字符拥挤与视觉裁切。
- **深浅色实时变色修复**：对接系统变色通道，解决深浅色切换时圆环变色滞后与系统图标色彩不匹配问题。
- **全链路功耗优化**：接入屏幕状态感知，屏幕熄灭后立即停止时钟后台循环与充电动画绘制，降低待机功耗。
## 功能变更
- **总开关与三合一解耦**：拆分独立的「模块总开关」与「启用三合一图标」，支持保留原生电池并将其他已启用组件在状态栏独立外显。
- **组件排布交互精简**：排布列表项改为点击直接唤起对应组件设置弹窗；移除顶部冗余的风格下拉菜单，统一由下方可视化卡片切换样式。
- **设置界面紧凑布局**：大幅收紧设置卡片与列表项间距，提升界面信息密度与视觉精致度。
- **默认启用智能防烧屏**：新安装后智能防烧屏默认开启，周期性微幅位移保护 OLED 屏幕防残影老化。
- **默认启用液体玻璃底栏**：底栏导航默认风格由悬浮样式调整为液体玻璃质感风格。
