# HonorDuo 1.0.0

荣耀 MagicOS 的三合一状态栏模块。宿主层、渲染引擎与设置界面统一采用 Kotlin 构建，包名 `io.github.odomu.honorduo`。

## 核心特性

### 1. 三合一字形与显示防护
- **三合一字形架构**：将状态栏右侧的 Wi-Fi、移动信号与电池融合为一体化紧凑字形，提供圆环与胶囊两种形态，切换即时自适应排版。
- **智能防烧屏机制**：内置针对 OLED 屏幕的微米级离散网格平移机制，每隔 30 秒沿 3×3 离散矩阵微幅位移 1dp，结合状态栏边界安全钳制，保护屏幕且功耗极低。
- **灵动胶囊智能避让与图标保护**：胶囊展开时基于屏幕物理坐标执行单组件碰撞避让，未受遮挡组件完全可见；智能识别并保护可用空间内的蓝牙、闹钟、网速等系统状态图标。

### 2. 移动信号与网络制式
- **信号柱风格支持**：支持 4 信号柱与 5 信号柱自由切换。5 柱风格具备全维度比例自适应，总宽度与 4 柱（225f）保持严格一致，柱宽、间距与圆点直径等比微缩，外轮廓对称协调。
- **双卡网络类型单独显示**：双卡上下两行文字高度严丝合缝撑满左侧双卡信号整体跨度，顶底两端锚定且整体几何中心对称对齐；读数外边距以 2px 为基准消除视觉粘连。

### 3. 时钟与硬件读数
- **多元日期格式支持**：提供月/日、年/月/日、月日、年月日四种清晰直观的排版格式，毫秒级即时联动状态栏。
- **电池高温告警机制**：支持电池温度告警阈值配置（30℃–60℃，默认 40℃），并支持深色与浅色模式独立配置告警颜色，温度越限即时变色提醒。
- **单行帧率自适应渲染**：独立单行帧率视图字号与网络类型保持一致比例，饱满清晰。

### 4. 界面交互与架构
- **三段式分类设计**：
  - **「组件排布」**：专注可视化全景实时预览、环内三分区交互点选、环外组件顺序拖拽与长按快速调整；
  - **「功能设置」**：精炼预览卡片直达各分类专属配置抽屉，抽屉顶部同步呈现快速实时预览；
  - **「关于模块」**：框架激活状态、系统界面一键重启与更新管理。
- **四字对称视觉规范**：核心分类标题与底栏 Tab 标题统一规范为规整对称的 4 个汉字。
- **模块化包结构**：代码划分为 `hook`、`model`、`render`、`ui` 架构层级。
