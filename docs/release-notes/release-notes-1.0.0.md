# HonorDuo 1.0.0

荣耀 MagicOS 的三合一状态栏模块，本分支首个版本。宿主层与设置界面均为 Kotlin 实现，包名
`com.honor.duo`。

## 功能

- **三合一字形**：状态栏右侧的 Wi-Fi、移动信号与电池合并成一个字形，圆环与胶囊两种样式，切换后
  宽度立即变化，旁边的图标按行规则让位。
- **三个位置、多候选**：上、中、下三个位置各是一份有序列表，排在前面的组件这一帧画不出来时由
  下一个顶上。
- **可放置组件**：电量数字、Wi-Fi 弧、移动信号点、网络制式、充电闪电、充电功率、运行功率、电池
  温度、帧率、时间都能单独放进位置，也能拆成卡一、卡二两排独立信号。
- **交还系统**：每样组件都能单独关闭，关闭后对应的原生图标回到原本位置，再打开时由模块接管。
- **充电时的环心**：充电时环中间显示电量百分比，拔线恢复原样；只覆盖这一帧，不改动排好的布局。
- **连 Wi-Fi 隐藏网络类型**：Wi-Fi 已连接时制式标签让位，断开或切到流量后恢复，三种样式统一生效。
- **胶囊尺寸**：长度可调（只拉长两端圆角之间的直段），两格各按自己的字号定宽、分别贴住内腔的
  左右缘，内边距由滑块统一控制（0–300%），字重上限 50。
- **Wi-Fi 弧尺寸**：在各自样式的适配空间内按 60–160% 放大，与描边滑杆互不影响。
- **温度随充电器走**：开启后温度只在充电时显示。
- **隐藏桌面图标**：只关掉桌面入口，LSPosed 里的设置页照常可开。
- **环外读数**：移动信号可移到电池旁边，两种堆叠样式（圆点副卡、双排柱）；网络制式可贴在信号
  上方，也可单独显示——单独显示时双卡各一条、对齐成列。充电功率、温度与帧率也能挂在环外，顺序
  可调。
- **状态栏时钟位**：时间放进字形后原生时钟让位；模块可在状态栏时钟位显示秒、年月日、星期与农历，
  并按状态栏高度排成两行。
- **充电动画**：呼吸、流光、电火花三种动效，充满或拔线即停，快充时速度翻倍。
- **逐项外观**：圆环粗细、弧线粗细、字号、字重、行距、点大小、闪电大小、轨道透明度与深浅色下的
  角色颜色都能分别调整。
- **点位编辑**：首页把字形放大画出，点图标上的哪个部位就改哪个部位；组件库列出全部组件，被关掉
  的也仍可进入设置。
- **预览场景**：可切换正常、充电、快充、低电量、危险等场景，改尺寸与颜色时所见即所得。
- **激活状态与更新**：关于页显示框架连接状态、版本与作用域，支持检查更新、下载安装与一键重启
  系统界面。

## 与 HyperDuo 的差异

| 维度 | HonorDuo 1.0.0 | HyperDuo 1.7.x |
| --- | --- | --- |
| 包名 / 版本线 | `com.honor.duo`，从 `1.0.0` 起算 | `io.github.yixing233.hyperduo`，`1.7.x` |
| 实现 | 宿主层、渲染、状态采样、设置界面统一 Kotlin | Java 宿主层 + Kotlin 设置界面 |
| 环外读数 | 圆点副卡 / 双排柱两种堆叠样式，制式双卡各一条 | 单一堆叠样式，制式单条 |
| 胶囊内边距 | 独立滑块（0–300%），只影响内容、不改宽度 | 内容固定贴内腔边缘 |
| 充电动画 | 呼吸 / 流光 / 电火花，速度可调 | 只有闪电本身 |
| 时钟 | 秒、年月日、星期、农历，附颜色与行距 | 仅字号与字重 |
| 帧率读数 | 有，可进环内或环外读数 | 无 |

两个应用可以并存安装，但不能互相覆盖升级；都会改动同一块状态栏，同一时间只应启用一个。

## 其他

- **全 Kotlin 实现**：`io.github.libxposed:api` 只在编译期引用，不随包分发。
- **字形是普通子视图**：不使用覆盖层窗口，宽度自行申报，画布与裁剪由系统提供，不参与触摸与
  无障碍焦点。
- **首次启动为空布局**：新安装不预置组件，由用户把组件放进上、中、下三个位置。
- **版本号来源统一**：APK 内的 `versionName` / `versionCode` 由发版脚本按版本号计算并注入。

---

**安装**：安装 `HonorDuo-1.0.0.apk`，在 LSPosed 中启用模块并勾选系统界面作用域，然后重启
系统界面。要求 Android 10 及以上与支持 libxposed API 102 的 LSPosed。
