# 1.0.6

## 功能添加
- **隐藏隐私指示**：功能设置 → 基础外观，新增开关（默认关闭）。状态栏右侧那个绿色圆点表示有应用正在使用相机或麦克风，开启后不再显示；关闭它等于关掉系统唯一的这项提醒，请按需开启。

## 功能修复
- **胶囊样式左右两侧留白**：组件外观 → 摆放，左右两侧的 Wi-Fi 位只在实际连上 Wi-Fi 时占位；关闭 Wi-Fi 或未连接时不再空出一道，字形重新居中。
- **胶囊下方副卡信号点**：胶囊下沿放置 SIM 1 / SIM 2 后，每张卡按自己的信号强度点亮，不再固定显示为未激活。
- **预览与真机一致**：设置页预览与状态栏用同一份 Wi-Fi 状态计算占位，预览里看到的宽度就是状态栏里的宽度。
- **状态栏时钟不再消失**：打开设置页的同时下拉通知栏，时间偶尔会一直不回来；现在行重新布局后会自动恢复。
- **横屏下拉后时钟异常**：横屏时下拉通知栏，时间会缩成看不见的一点；状态栏高度未测出的那一帧不再把字号压成 0。
- **字形与环外读数不再丢失**：状态栏重新布局后，三合一字形、信号读数、性能读数与制式标签会自己补回原位。
- **恢复配置立即生效**：恢复备份后，农历开关、日期/星期格式、上下行偏移、行距、间距与颜色会一并同步到状态栏，不再需要再改一次设置才显示。
- **减少状态栏重复布局**：状态栏布局同步只在尺寸、顺序或内容实际变化时更新，避免下拉和高频刷新时重复测量。
