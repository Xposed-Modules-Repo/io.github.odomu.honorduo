# 1.0.5

## 新增功能
- **支持左右两侧组件**：左右两侧可放置信号点与 Wi-Fi 弧形，信号点与上下缺口使用同一套柱数与点大小设置。
- **支持显示信号强度**：支持在状态栏实时显示当前提供移动数据的上网卡信号强度；开启路径在「功能设置 → 性能读数 → 信号强度」。
- **支持设置生效范围**：「基础外观」中提供多选生效范围菜单，排除范围的将自动恢复出厂原生电池与网络图标。
- **支持显示蓝牙电量**：支持将已连接蓝牙耳机的剩余电量单独显示和三合一显示。
- **支持隐藏HD图标**：在「下拉面板」中提供独立开关，支持按需隐藏状态栏及下拉面板中的「HD / VoLTE」高清通话图标以及「VoWiFi」图标。
- **支持隐藏系统通知**：在「下拉面板」中提供独立开关，支持按需隐藏「极速充电/USB充电」、「热点共享」与「USB 调试」的常驻系统通知。
- **支持天气交互**：支持在通知中心日期行实时显示天气与温度，点击日期区域可直接快捷打开系统天气应用。

**安装**：覆盖安装即可，设置全部保留。
