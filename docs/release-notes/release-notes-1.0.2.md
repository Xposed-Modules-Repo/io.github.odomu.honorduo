# 1.0.2

## 功能添加
- **状态栏实时天气**：功能设置 → 状态栏时钟 → 显示天气，读取 MagicOS 气象数据并在时钟旁显示天气与气温；五种样式：
  - **纯文本**（默认）：`雾 18°C`；
  - **矢量图标**：模块自绘的矢量天气图形，跟随天气颜色；
  - **矢量+文本**：自绘图形 + 文字与气温；
  - **字体符号**：系统字体的天气符号（多为彩色 emoji）；
  - **符号+文本**：字体符号 + 文字与气温。
- **时钟行显示顺序**：功能设置 → 状态栏时钟 → 行显示顺序：
  - **日期在上**：第一行日期、星期、天气，第二行农历、时间；
  - **时间在上**：第一行时间、天气，第二行日期、农历、星期。
- **通知面板**：设置页新增独立分组，四项开关：
  - **隐藏关机**：收起控制中心右上角的电源按钮；
  - **隐藏铃铛**：移除通知中心大时间旁的通知管理入口；
  - **显示农历**：在通知中心日期行追加农历；
  - **显示天气**：追加实时天气与气温，支持纯文本 / 图标 / 符号样式。
- **状态图标隐藏**：基础外观新增 **隐藏闹钟**、**隐藏蓝牙**，按槽位隐藏图标，闹钟照常响、蓝牙照常工作。
- **隐藏时钟**：时钟设置首行的总开关，系统时钟与三合一自绘时钟一并隐藏。
- **温度状态颜色**：硬件读数新增状态颜色开关（默认关闭），电池温度超过阈值以高亮告警色显示。
- **替换状态图标 / WiFi 图标**：把闹钟、NFC、热点、VPN、蓝牙、静音、勿扰及 Wi-Fi 图标替换为内置风格（支持 Wi-Fi 5/6/7）。
- **圆环双卡双排堆叠**：双卡在环内时支持双排同心堆叠，外轮廓对称对齐正圆外径。
- **圆环间距微调**：基础外观新增左右、上下间距滑块，调节圆弧与内部读数的相对间距。
- **自定义字体导入**：关于模块 → 字体，导入 `.ttf` / `.otf` 应用于三合一全部文本与读数，可一键恢复系统字体。
- **充电闪电动画**：电池电量新增充电动画开关，支持呼吸、流光、电火花三种风格与速度调节。
- **组件快捷调位**：排布弹窗顶部新增位置下拉，可快速切换环内区域；添加未开启的组件时自动同步激活其开关。
- **在线更新日志与新版提醒**：关于模块 → 更新，支持在线查阅版本说明，检测到新版本时显示红点徽标。

## 功能修复
- **环外堆叠信号吞掉整行宽度**：改为按实际墨迹精确测量，修复信号撑满父容器导致三合一图标被挤出屏幕、其他图标不显示的问题。
- **组件重排丢失布局参数**：重排子视图时保留原有外边距与垂直居中属性，消除间距失效与错位。
- **时钟行距与对齐**：上下间距滑块全程生效（默认 0）；每行宽度按实际绘制字号测量，消除整行偏移；时间、温度、图标、农历统一按数字墨迹居中。
- **天气图标溢出**：图标尺寸按数字 cap 高定标，不再越过文字行挤压下一行。
- **通知中心日期行**：农历/天气为追加显示，不再覆盖原日期。
- **温度样式与阈值即时生效**：修改电池高温阈值或重置颜色后立即刷新。
- **颜色配置默认浅色页签**：颜色弹窗默认选中浅色背景，避免误判未生效。
- **恢复默认语义统一**：统一各页「恢复默认」按钮与确认提示。
- **应用更新下载**：新增实时百分比与线性进度，下载完成自动唤起安装器。
- **信号环内适配**：「仅显示上网卡」与 4/5 柱样式在圆环、胶囊内同样生效。
- **状态栏时钟排版**：修复无法双行堆叠日期星期、以及横屏下拉通知栏时被系统误加左侧偏移的问题。
- **胶囊避让与层级稳定**：被展开胶囊覆盖的图标严格隐藏，消除下拉时的空指针闪退。
- **环内字号与空间预算**：优化网络类型与电量读数的默认字号，消除拥挤与裁切。
- **深浅色实时变色**：对接系统变色通道，修复变色滞后与图标色彩不匹配。
- **全链路功耗**：接入屏幕状态感知，熄屏即停时钟循环与动画绘制。

## 功能变更
- **总开关与三合一解耦**：拆分「模块总开关」与「启用三合一图标」，可保留原生电池并让其他组件独立外显。
- **排布交互精简**：列表项点击直接打开对应设置弹窗，移除顶部冗余下拉，样式统一由可视化卡片切换。
- **设置界面紧凑**：收紧卡片与列表项间距，提升信息密度。
- **默认值调整**：新装默认开启智能防烧屏与液体玻璃底栏；时钟上下间距默认 0。
